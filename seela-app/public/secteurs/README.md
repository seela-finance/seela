# Images des pages Secteur

Déposez ici les photos (banque d'images) des pages secteur. **Les noms de fichiers doivent être exactement** ceux ci-dessous — l'image remplace alors automatiquement le placeholder, sans aucune modification de code.

Tant qu'un fichier est absent, le placeholder (avec la description de la photo à sourcer) reste affiché.

- Format : **`.jpg`** (obligatoire, c'est l'extension attendue par le code)
- 3 photos par secteur : `hero` (paysage ~4:3), `equipement` (~4:3), `ambiance` (large ~21:9)
- Conseil : images horizontales, ≥ 1600 px de large, optimisées (< 300 Ko idéalement)
